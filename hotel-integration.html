Integração Frontend-Backend

Frontend:
  • Local: /hotel-admin/
  • Tecnologias: Bootstrap 5, JavaScript Vanilla
  • Páginas: dashboard.html, quartos.html, reservas.html, hospedes.html
  • Armazenamento: localStorage (dados temporários)
Backend:
  • Local: /hotel-backend/
  • Tecnologias: Node.js, Express, SQLite
  • Porta: 3001
  • API: RESTful com endpoints CRUD
Configuração de Integração:
Para integrar o frontend com o backend, adicione o seguinte script ao frontend: 
const API_BASE_URL = 'http://localhost:3001/api';
