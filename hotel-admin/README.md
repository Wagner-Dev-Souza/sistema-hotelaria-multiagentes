# Sistema de Hotelaria - Interface Administrativa

Um sistema completo de gerenciamento hotelar com interface web moderna e responsiva.

## 🏨 Visão Geral

Esta interface administrativa foi desenvolvida para gerenciar operações de hotel, incluindo:
- Dashboard com métricas em tempo real
- Gerenciamento de quartos
- Controle de reservas com calendário
- Cadastro e histórico de hóspedes

## 🚀 Funcionalidades

### Dashboard Principal
- Taxa de ocupação do hotel
- Receita diária
- Número de reservas ativas
- Hóspedes atuais
- Gráficos visuais de ocupação e receita
- Atividades recentes

### Gerenciamento de Quartos
- Listagem completa de todos os quartos
- Filtros por status (Disponível, Ocupado, Manutenção)
- Filtros por tipo (Simples, Duplo, Suíte, Presidencial)
- Busca por número ou tipo
- Adicionar, editar e excluir quartos
- Status em tempo real

### Sistema de Reservas
- Calendário interativo visualizando reservas
- Listagem detalhada de todas as reservas
- Filtros por status (Confirmada, Check-in, Check-out, Cancelada)
- Busca por hóspede ou número do quarto
- Adicionar novas reservas
- Cancelar reservas
- Visualizar detalhes completos

### Gerenciamento de Hóspedes
- Cadastro completo de hóspedes
- Histórico de hospedagens
- Busca por nome, email ou documento
- Adicionar, editar e excluir hóspedes
- Informações de contato completas

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript Vanilla
- **Framework UI**: Bootstrap 5
- **Ícones**: Font Awesome 6.4.0
- **Armazenamento**: localStorage (dados temporários)
- **Design**: Interface responsiva e moderna
